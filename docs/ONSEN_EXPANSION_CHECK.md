# 温泉データ拡充チェック

## 2026-08-14 確認内容

ローカルの `/onsens/` をブラウザで確認し、温泉一覧に都県ラベル、エリア名、詳細リンク、公式サイトリンク、画像クレジットが表示されることを確認した。追加された東京都（大島・式根島・八丈島・奥多摩・秋川渓谷・檜原）、神奈川県（鶴巻・中川・あつぎ・陣馬・奥湯河原・仙石原）、千葉県（房総・九十九里の各温泉）などのカードも一覧に含まれている。

神奈川県観光協会の公式特集ページでは、鶴巻温泉、中川温泉、あつぎ温泉郷、陣馬の湯、箱根十七湯、奥湯河原温泉が掲載されていることを確認した。千葉県公式観光サイトでは、たてやま、白浜、千倉、岩井、鴨川、小湊、勝浦、白子、養老渓谷、木更津、亀山、犬吠埼の温泉地が掲載されていることを確認した。大子町観光協会、養老渓谷観光協会も公式ページとして確認した。

データ検証は成功し、Next.js本番ビルドでは動的温泉詳細・旧互換ドキュメントを含めて144ルートが静的生成された。
