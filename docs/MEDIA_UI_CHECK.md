# 画像・施設導線・デザイン確認

2026-08-14にローカルの温泉一覧と草津温泉詳細ページを確認した。

一覧ページでは各カードに温泉画像、都県・エリア、詳細を見る、公式サイト、Googleマップ、3件の施設案内・地図リンク、画像出典が表示された。詳細ページではヒーロー画像、公式情報カード、Googleマップで周辺を見る、公式案内・宿泊・日帰りの3施設カードが表示された。

画像は日本語Wikipediaの公開REST APIから45件を更新し、既存画像を含めて全55件が有効な画像メタデータを持つ。データ検証とNext.js本番ビルドは成功し、144ルートが静的生成された。

カード、リンク、施設枠は生成り・茶・金・藍を基調とした和風配色へ変更した。詳細ページの草津温泉では、温泉街の写真をヒーローに表示できていることを確認した。
