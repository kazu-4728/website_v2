# コンテンツ・画像ソーシング登録簿

**調査開始日：2026年8月17日**

## 情報源の利用方針

温泉地・日帰り施設の基本情報は、施設公式サイト、自治体・観光協会、公的統計を優先する。画像は「無料で閲覧できる」だけでは採用せず、対象との一致、再利用条件、著作者表記の要否を画像単位で確認する。確認が終わるまで既存の無関係画像を表示しない。

## 取得時の記録

塩原温泉ビジターセンターのCommonsファイルは、作者Abasaaによるパブリックドメイン作品であり、対象説明も塩原温泉ビジターセンターと一致することを確認した。[3] 一方、画像配信元から連続取得時にHTTP 429（レート制限）が発生したため、対象の画像は台帳の候補として保持し、ローカル保存は配信制限が解消してから実施する。未取得の画像を表示済みとしては扱わない。

## 赤城温泉郷：リンク修正の確認（2026年8月17日）

旧URL `https://www.akagi-kanko.net/` は名前解決できなかったため、赤城温泉の案内先は群馬県公式観光サイトのスポットページへ切り替える。群馬県公式ページは赤城温泉を前橋市の温泉地として案内し、泉質、アクセス、日帰り利用の有無を掲載している。[4]

赤城温泉ホテルの公式サイトも稼働を確認した。これは温泉地全体ではなく同施設の案内として扱う。[5] 前橋観光コンベンション協会の「前橋市内の湯どころ」は、赤城温泉郷の宿と日帰り温泉を含む地域案内として利用できる。[6]

[4] [群馬県観光公式：赤城温泉](https://gunma-kanko.jp/spots/1359)

[5] [赤城温泉ホテル公式サイト](https://akagionsen.com/)

[6] [前橋まるごとガイド：前橋市内の湯どころ](https://www.maebashi-cvb.com/feature/onsen/top)

## 個別画像の追加に関する再監査（2026年8月17日）

Openverseで個別画像が未登録の133温泉地を名称検索したところ、75件で候補が返った。ただし検索結果には同名の別地域・別温泉の写真も含まれる。例として大滝・秩父の検索に松之山温泉の写真、館山の検索に奥飛騨の写真が混在した。このため、候補の存在だけをもって温泉地の画像として採用してはならず、タイトル・説明・撮影場所・ライセンスを温泉地ごとに照合する必要がある。

個別画像の不足を地域画像で恒久的に補う方針は撤回し、対象一致または撮影場所が明記された近隣写真だけを個別レコードへ登録する。
