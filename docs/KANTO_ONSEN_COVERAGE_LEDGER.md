# 関東温泉地 網羅台帳

**最終更新：2026年8月17日**

この台帳は、関東7都県の温泉地を網羅するための作業管理文書です。環境省統計の「温泉地数」は**宿泊施設のある場所**を単位とします。一方、サイトには日帰り温浴施設も別レコードとして掲載するため、二つの指標を混同しません。[1]

> この台帳でいう「差分」は、現時点のサイト上の温泉地レコード数と公的統計の件数との参考差分です。同一温泉地の重複、表記ゆれ、統計上の単位差を正式に照合するまで、未掲載温泉地の確定件数とは扱いません。

## 完全網羅の定義

温泉地を「掲載済み」とするには、少なくとも以下を満たす必要があります。

| 確認項目 | 必須基準 |
|---|---|
| 名称と所在地 | 都道府県・市町村・温泉地名を一次または公的観光情報で確認する。 |
| 種別 | 宿泊を伴う温泉地、日帰り温浴施設、温泉銭湯を区別して登録する。 |
| 公式導線 | 施設公式、温泉組合、自治体・観光協会のいずれかにリンクする。 |
| 日帰り情報 | 日帰り利用がある場合、営業時間、料金、休館・年齢等の重要条件、アクセス、確認日を登録する。 |
| 説明 | 固有の泉質、地理、周辺体験、利用向けの情報を根拠に基づいて記述する。 |
| 画像 | 対象と一致し、再利用ライセンスまたは掲載許諾が確認できた画像のみ掲載する。未確認なら画像を表示しない。 |

## 作業順序

日帰り需要が高く、公共交通または車で訪問しやすい都市近郊の施設を先に整備します。温泉地の網羅は、統計の件数だけで名称を推測せず、都県ごとの名称台帳を確定してから追加します。

| バッチ | 対象 | 到達条件 |
|---|---|---|
| 1（実施済み） | 東京都の日帰り需要が高い13施設 | 日帰りガイド、公式導線、誤画像の非表示、情報確認日の付与 |
| 2 | 箱根・湯河原、群馬、栃木の主要日帰り施設 | 各施設についてバッチ1と同じデータ品質を満たす |
| 3 | 千葉・埼玉・茨城の都市近郊日帰り施設 | 公式情報、アクセス、利用条件を施設単位で補強 |
| 4 | 7都県の温泉地名称台帳 | 統計上の温泉地とサイトレコードを1対1で照合し、表記ゆれ・重複・未掲載を確定 |
| 5 | 未掲載温泉地の追加 | 1温泉地ごとに根拠、説明、宿泊・日帰りの導線、適切な画像をそろえて追加 |

## 画像の扱い

施設公式サイトに掲載される写真は、原則として運営者の著作物です。公式サイト上に存在することだけでは、第三者のポータルサイトへの転載許可にはなりません。そのため、バッチ1では対象と無関係な既存写真を非表示とし、**Wikimedia Commons等で対象・ライセンスを確認できる画像、または運営者から利用許諾を得た公式写真**に限って差し替える方針に変更しました。
