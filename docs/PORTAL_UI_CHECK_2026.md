# 新温泉ポータルUI確認

確認日: 2026-08-15

## ホーム

`http://localhost:3000/` で、ヒーロー、目的別導線、92件・11エリア・7都県のサマリー、関東7都県の簡略マップ、都県別リンク、エリアカード、特集温泉、記事導線が表示されることを確認した。マップ上の東京・神奈川・千葉・埼玉・群馬・栃木・茨城の各ノードは `/onsens?prefecture=...` へリンクする。

アクションは「温泉を探す」「全温泉を一覧で見る」「エリアガイドを見る」「詳細を見る」などを濃い茶色と生成り色の高コントラストボタンへ統一した。

## 詳細ページ

`http://localhost:3000/onsens/kusatsu/` で、草津温泉の湯畑画像、複数画像ギャラリー、公式案内、Googleマップ、泉質（酸性泉・硫黄泉）、入浴体験、特徴、季節ガイド、宿泊・日帰り施設、関連温泉が表示されることを確認した。ギャラリーの2・3枚目は「周辺の温泉地・自然風景」と明示し、地域周遊の参考画像として区別している。

## 画像・リンク監査

全92温泉の `gallery` は3枚、必須項目（features、benefits、seasonal、editorialNote）を保有する。公式URLの並列監査では92件中86件がHTTP到達、HTTP 4xx/5xxは0件、6件は外部サイトのネットワークタイムアウト扱いだったため、検索で確認した観光協会・自治体・公式施設URLへ置換した。
